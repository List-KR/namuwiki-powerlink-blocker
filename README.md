# 나무위키 파워링크 광고차단 유저스크립트
`namuwiki-powerlink-blocker` 유저스크립트는 인터넷 웹사이트 [나무위키](https://namu.wiki)의 네이버 파워링크 광고를 차단합니다.

# 설치 방법
[Tampermonkey](https://www.tampermonkey.net/), [Greasemonkey](https://addons.mozilla.org/ko/firefox/addon/greasemonkey/) 또는 호환되는 유저스크립트 확장 프로그램이 필요합니다.

Chrome의 경우 Manifest V3 도입으로 인해 유저스크립트의 원활한 작동을 보장하지 못할 수 있으며, 이 유저스크립트는 Mozilla Gecko 기반의 브라우저를 우선 지원합니다.

유저스크립트 확장 프로그램을 설치하셨다면 아래 링크를 클릭하여 유저스크립트를 추가해주세요. 호환되는 확장 프로그램이 설치된 경우 자동으로 감지합니다.

**https://cdn.jsdelivr.net/gh/List-KR/namuwiki-powerlink-blocker/namuwiki-powerlink-blocker.user.js**

# 주의 사항
나무위키 측에서 수시로 파워링크 차단을 어렵게 하기 위해 구조를 변경하고 있으므로, 오탐지가 발생할 수 있습니다.

잘못 차단된 경우 10초 정도 이내에 원상 복구되게 설계하였으나 절대적인 것은 아니며, 오탐지가 발생한 경우 [이슈 트래커](https://github.com/List-KR/namuwiki-powerlink-blocker/issues)에 이슈를 생성해주세요.
